蓝色：需要你参与 灰色：全自动，不用管

你只需要改三个文件

说白了就两句话：

你想达到的效果改哪个文件
想多抓一个网站 / 多盯一个 X 账号 sources.json —— 照着已有格式加一行就行
不想看到某类内容（比如币圈、赌球） settings.json 里的 exclude_keywords —— 默认已经排掉了美股港股、币圈合约、外汇、赌博、色情、诈骗刷单
想换个选题方向（比如"AI 工具评测"） topics.json —— 加一个主题，再把相关来源指过去

一天里它自己会做什么

为什么非得用 GitHub 和 Cloudflare

因为要抓的是 X、Reddit 这类在国内打不开的网站。

GitHub 和 Cloudflare 的服务器在国外，它们抓得到；你我这台电脑在国内，直接抓就是超时——这正是之前实测的结果：Reddit、YouTube 在本机全部连不上，但换到 GitHub 的服务器上就都通了。

所以这套组合的分工是：GitHub 出服务器和定时器，Cloudflare 出数据库和免费额度，两边都在免费范围内。

常见问题

要一直开着电脑吗？ 不用。抓取在 GitHub 的服务器上跑，跟你电脑开不开机没关系。
要花钱吗？ 不用。目前源数量、抓取频率、数据量都在免费额度内。
抓来的东西存在哪？ Cloudflare 的数据库里，保留最近 30 天，过期自动清。
怎么让它给我出选题？ 直接跟我说"出今天的选题"就行。我会把最近一天的内容按主题挑一遍，凑不出至少 3 个具体数字的选题会降到备选。
X 是怎么抓的？不是要付费吗？ X 官方接口免费版每月只给 1500 条，付费要 200 美元一个月，所以走了开源的 Nitter 镜像，它提供 RSS 订阅，目前 9 个 X 源全部能正常抓到。
